# 帆船赛现场控制和申诉处理

源提示词摘要：竞赛官维护组别、航线、起航时间和处罚记录，计时员提交到达数据，裁判处理抗议、重赛、弃权和成绩更正；冲突或重复处罚进入复核，操作保留时间线。

## 技术栈

React 19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62024`

## 系列赛记分与重算规则

- **多轮系列赛**：每轮按净用时（用时 + 处罚）排名记分，第 1 名 1 分。
- **剔除最差轮**：有效轮超过 1 个时，每船总分自动剔除最差一轮；只剩一个有效轮时不剔除。
- **改判 / 作废联动**：抗议改处罚、整轮成绩更正、轮次作废或恢复，都会让在版总名次退回，按当前还有效的成绩重新计算——之前被顶掉的那场会重新参与比较。
- **版本留档**：总名次每次重算生成新版本（v1、v2…），旧版进历史列表只读查看；版本里记录各轮当时的修订号。
- **乐观锁修订号**：每轮有 `revision`，成绩每写入一次就 +1。保存或改判必须带打开时的修订号，两人同时改同一轮时，后到者会收到 `conflict` 和当前修订号，整批拒绝，重读后才能再提交。
- **部分失败重试**：批量保存按条写入，个别条目瞬时失败只返回 `failedIds`，已写入的生效并推进修订号；重试只发没写进去的条目。
- **旧数据迁移**：没有轮号的单场成绩自动挂到唯一有效的一场（`regatta-control-v1` → `regatta-control-v2`），补齐轮号、作废状态和修订号。

## 页面

- 竞赛控制：轮次切换、起航倒计时、比赛状态切换、作废 / 恢复轮次。
- 成绩管理：按轮批量编辑净用时和处罚秒数，显示修订号、冲突提示、部分失败重试，可模拟并发修改与瞬时写入失败。
- 总名次：在版总名次（每轮得分、被剔除轮、总分）与旧版历史查看。
- 抗议与申诉：提交抗议、复核、接受改判（+处罚秒数，带修订号校验）或驳回；冲突或重复处罚进入复核，操作保留时间线。

## 校验

```bash
npm run check      # TypeScript
./node_modules/.bin/esbuild scripts/verify.ts --bundle --platform=node --format=esm --outfile=/tmp/verify.mjs && node /tmp/verify.mjs
```

`scripts/verify.ts` 覆盖：剔最差轮、作废 / 恢复重算、版本留档、乐观锁冲突、部分失败只重试未写入条目、作废轮拒写、旧数据迁移。
